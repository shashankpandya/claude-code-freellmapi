## Reporting Issues

When opening an issue, include:

| Information | Why It's Needed |
|------------|----------------|
| Operating System | Issues may be OS-specific |
| Error message (exact) | Helps diagnose problem |
| Steps to reproduce | Helps verify the issue |
| Configuration | Shows your setup |
| Logs | Helps debug |
