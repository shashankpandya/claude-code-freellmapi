# Contributing

Thank you for considering contributing to Claude Code with FreeLLMAPI + LiteLLM!

## How to Contribute

1. **Fork the Repository**
2. **Clone Your Fork**
3. **Create a Branch** for your changes
4. **Make Changes** with clear, descriptive commits
5. **Push to Your Fork**
6. **Open a Pull Request**

## Code of Conduct

By participating, you agree to uphold our [Code of Conduct](./CODE_OF_CONDUCT.md).

## Reporting Issues

Found a bug or have a suggestion? [Open an issue](https://github.com/shashankpandya/claude-code-freellmapi/issues) with:
- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment details
